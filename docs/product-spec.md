# CyberTown MVP 产品边界

## 验收目标

单个共享小镇容纳 10–20 名测试用户，每人一个居民。测试者连续七天回来查看居民经历，并至少三次主动改变居民的后续计划。

## 核心体验

1. 玩家通过邀请码注册，不要求邮箱验证。
2. 外观与背景随机，可有限重抽；性格从三个随机候选中选择；所有居民初始能力总值相等。
3. 玩家可为居民输入自然语言目标，并附带最多两条限制。
4. 居民在玩家离线时继续行动，每个现实日对应一个小镇日。
5. 行动限定为 `REST`、`WORK`、`TALK`、`EXPLORE`、`HELP`，服务端保存事实，AI 只负责受约束的决策与叙事。
6. 玩家能查看当日日报，并在后续时段改变计划。
7. 玩家可发送附近可见的聊天气泡；它不是一对一私聊，并需要发送频率限制。

## MVP 非目标

- 不做多小镇、开放世界、交易市场或完整农场经营系统。
- 不以自由生成文本直接修改金币、属性或世界事实。
- 不依赖 AI 服务才能推进小镇时间。
- 首发不承诺 iOS；待具备 macOS 与 Xcode 环境后再导出和签名。

## 约束

- 单人开发周期 6–8 周。
- 测试期 AI 月预算不超过人民币 200 元。
- 每位居民每天最多 4 次模型调用，超限或失败时走确定性规则引擎。
- 内容面向 12+，后台需要事件追踪、封禁/禁言与审计能力。
